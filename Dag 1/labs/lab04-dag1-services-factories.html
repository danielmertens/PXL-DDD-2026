Lab 4 — Domain services en factories

Starter

Dag 1/DDD.Domain — verder dan lab 3

Opdracht

  1. Voeg domain services toe aan je aggregates of value objects.
  2. Voeg een factory toe voor een value object.
  3. Wat merk je op?

Suggesties

Kies er één of meer uit elke kolom.

Domain services

  • UsernameAvailabilityService — is de username nog niet in gebruik door een andere user?
  • DuplicateSongService — bestaat er al een song met dezelfde title?
  • CanPlaySongService — mag deze user deze song afspelen?

Factories voor een value object

  • UsernameFactory — trimt en valideert de ruwe invoer
  • DurationFactory — maakt een duration uit tekst zoals 3:45
  • TitleFactory — trimt en bewaakt de maximale lengte

Klaar wanneer

een domain service een regel afhandelt die niet in de aggregate thuishoort, en een value object via een factory gecreëerd wordt.
