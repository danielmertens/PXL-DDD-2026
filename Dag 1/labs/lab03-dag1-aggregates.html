Lab 3 — Aggregates

Starter

Dag 1/DDD.Domain — verder dan lab 2

Opdracht

  1. Creëer aggregates en begin met User of Song.
  2. Implementeer per aggregate commands en events.

Suggesties voor domain commands

Kies er drie bij de aggregate waarmee je start.

User

  • RegisterUser — username mag niet leeg zijn
  • ChangeUsername — de nieuwe username mag niet leeg zijn
  • DeactivateUser — een al gedeactiveerde user kan niet opnieuw gedeactiveerd worden

Song

  • AddSong — title en duration zijn verplicht
  • ChangeTitle — title mag niet leeg zijn
  • RemoveSong — een al verwijderde song kan niet nog eens verwijderd worden

Klaar wanneer

een command de state mutert via events, en een overtreden domain rule een exception gooit.
